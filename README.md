# PXE autoinstall server for Ubuntu 26.04 and 22.04

One script that turns an Ubuntu server into a UEFI PXE boot server. Boot a machine or VM from the network, pick a menu entry, and it installs Ubuntu Server unattended.

## What it sets up

- **DHCP** (`isc-dhcp-server`) pointing clients at the TFTP server
- **TFTP** (`tftpd-hpa`) serving signed shim + GRUB (Secure Boot works) and the installer kernels
- **Apache** serving the ISOs (`/images`) and the autoinstall files (`/ks`)
- Boot menu with two entries:
  - Ubuntu 26.04.1 LTS (default)
  - Ubuntu 22.04.5 LTS

## Requirements

- PXE server: Ubuntu server with a static IP and about 10 GB free disk (two ISOs)
- **Client machine or VM: 8 GB RAM recommended.** The installer loads the whole ISO into memory. It may work with less, but 26.04 failed at about 40% of the download on a VM with too little RAM (`no space left on device`, `unable to find a live file system`). Give VMs at least a 20 GB disk.
- UEFI boot only (Hyper-V Generation 2, or UEFI hardware)

## Install

```bash
wget https://raw.githubusercontent.com/jbrek/tftp-pxe-ubuntu22/main/tftp-pxe-install.sh
sudo bash tftp-pxe-install.sh
```

The server IP is detected automatically.

## Change the default login before you use it

The installed machine gets this account from `user-data`:


**Change both before real use.** Edit `/ks/user-data` on the server (or fork this repo and edit `user-data`):

```bash
openssl passwd -6          # prints a new password hash, paste it into `password:`
```

```yaml
  identity:
    hostname: linux
    username: yourname
    realname: yourname
    password: <hash from openssl passwd -6>
```

The default `user-data` also enables SSH password login (`allow-pw: true`) and installs the `powershell` snap. Edit it to suit.

## Use

1. Boot the client from the network (UEFI PXE / IPv4).
2. Pick the Ubuntu version from the menu.
3. Wait. It downloads the ISO, installs, and reboots into the new system.

## Files

| Path | Purpose |
|---|---|
| `/srv/tftp/` | `bootx64.efi`, `grubx64.efi`, `grub/grub.cfg`, kernels in `ubuntu26/` and `ubuntu22/` |
| `/images/ubuntu26`, `/images/ubuntu22` | ISOs served over HTTP |
| `/ks/user-data`, `/ks/meta-data` | autoinstall config |
| `/etc/dhcp/dhcpd.conf` | generated (original saved as `.original`) |

`grub.cfg` and `dhcpd.conf` are generated by the script. Only `user-data` is downloaded from this repo.

## Change the Ubuntu versions

Edit these lines at the top of the script (URLs must exist on `releases.ubuntu.com`):

```bash
ISO26=ubuntu-26.04.1-live-server-amd64.iso
ISO22=ubuntu-22.04.5-live-server-amd64.iso
```

## Troubleshooting

- **`tftpd-hpa` fails to start (`cannot open IPv6 socket`):** IPv6 is disabled on the server. The script already forces IPv4 in `/etc/default/tftpd-hpa` (`TFTP_ADDRESS="0.0.0.0:69"`, `--ipv4`).
- **`isc-dhcp-server` not found:** ISC DHCP is end-of-life, and newer Ubuntu releases may drop it. The script stops with a message. dnsmasq or Kea can replace it.
- **Client gets no menu:** check `systemctl status isc-dhcp-server tftpd-hpa` and `sudo journalctl -u isc-dhcp-server`.
- **Download stalls or `no space left on device`:** the client has too little RAM. See Requirements.
- **Check the ISOs are served:** `curl -I http://<server-ip>/images/ubuntu26/ubuntu-26.04.1-live-server-amd64.iso`
